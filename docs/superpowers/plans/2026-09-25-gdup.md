# gdup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `gdup`, a Windows CLI that uploads one large file to Google Drive over a single tuned resumable-upload stream, optionally pinned to a chosen network interface, with rclone-style saved OAuth credentials.

**Architecture:** A .NET 10 console app with focused folders: `Config` (INI + DPAPI + rclone import), `Auth` (OAuth loopback/PKCE + token refresh), `Net` (NIC selection + socket-bound `HttpClient`), `Drive` (folder resolution, resumable uploader, session persistence), `Output` (progress), `Cli` (System.CommandLine wiring). The uploader is tested end-to-end against an in-process fake Drive server implemented as an `HttpMessageHandler`.

**Tech Stack:** C# / .NET 10 (`net10.0-windows`), System.CommandLine 2.0.12, System.Security.Cryptography.ProtectedData 10.0.12, xUnit 2.9.

**Spec:** `docs/superpowers/specs/2026-09-25-gdup-design.md`

## Global Constraints

- Target framework `net10.0-windows` for both projects; `Nullable` and `ImplicitUsings` enabled; `InvariantGlobalization` true in the app.
- Only NuGet dependencies in the app: `System.CommandLine` 2.0.12 and `System.Security.Cryptography.ProtectedData` 10.0.12. No Google SDK.
- Config file: `%APPDATA%\gdup\gdup.conf`; session state: `%LOCALAPPDATA%\gdup\sessions\*.json`.
- Secrets (`client_secret`, `token`) are stored as `dpapi:` + base64 (CurrentUser scope); plain values are accepted on read.
- Chunk size: default 256M, must be a multiple of 256 KiB, max 4G.
- HTTP: HTTP/1.1 only, `AllowAutoRedirect = false`, socket `SendBufferSize = 8 MiB`, `NoDelay = true`, `HttpClient.Timeout` infinite.
- Stall timeout default 60 s, minimum 5 s.
- Exit codes: 0 success, 1 usage/config error, 2 upload failed (incl. Ctrl+C), 3 checksum mismatch.
- Every commit message ends with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (use a second `-m`).
- All commands run from the repo root `H:\Source\repos\GoogleDriveResume` in Git Bash.

```csharp
using System.Text;

namespace Gdup.Config;

/// <summary>Minimal rclone-compatible INI: [section] headers and "key = value" lines.</summary>
public sealed class IniFile
{
    private readonly List<IniSection> _sections = [];

    public IReadOnlyList<IniSection> Sections => _sections;

    public IniSection? Get(string name) =>
        _sections.FirstOrDefault(s => string.Equals(s.Name, name, StringComparison.OrdinalIgnoreCase));

    public IniSection GetOrAdd(string name)
    {
        var section = Get(name);
        if (section is null)
        {
            section = new IniSection(name);
            _sections.Add(section);
        }
        return section;
    }

    public bool Remove(string name) =>
        _sections.RemoveAll(s => string.Equals(s.Name, name, StringComparison.OrdinalIgnoreCase)) > 0;

    public static IniFile Parse(string text)
    {
        var ini = new IniFile();
        IniSection? current = null;
        foreach (var raw in text.Split('\n'))
        {
            var line = raw.Trim();
            if (line.Length == 0 || line[0] == '#' || line[0] == ';') continue;
            if (line[0] == '[' && line[^1] == ']')
            {
                current = ini.GetOrAdd(line[1..^1].Trim());
                continue;
            }
            var eq = line.IndexOf('=');
            if (eq <= 0 || current is null) continue;
            current[line[..eq].Trim()] = line[(eq + 1)..].Trim();
        }
        return ini;
    }

    public override string ToString()
    {
        var sb = new StringBuilder();
        foreach (var section in _sections)
        {
            sb.Append('[').Append(section.Name).Append("]\n");
            foreach (var (key, value) in section.Entries)
                sb.Append(key).Append(" = ").Append(value).Append('\n');
            sb.Append('\n');
        }
        return sb.ToString();
    }
}

public sealed class IniSection(string name)
{
    private readonly List<KeyValuePair<string, string>> _entries = [];

    public string Name { get; } = name;

    public IReadOnlyList<KeyValuePair<string, string>> Entries => _entries;

    public string? this[string key]
    {
        get
        {
            var i = IndexOf(key);
            return i < 0 ? null : _entries[i].Value;
        }
        set
        {
            var i = IndexOf(key);
            if (value is null)
            {
                if (i >= 0) _entries.RemoveAt(i);
            }
            else if (i < 0)
            {
                _entries.Add(new(key, value));
            }
            else
            {
                _entries[i] = new(_entries[i].Key, value);
            }
        }
    }

    private int IndexOf(string key) =>
        _entries.FindIndex(e => string.Equals(e.Key, key, StringComparison.OrdinalIgnoreCase));
}
```

```csharp
using System.Security.Cryptography;
using System.Text;

namespace Gdup.Config;

/// <summary>Encrypts config secrets for the current Windows user.</summary>
public static class Dpapi
{
    public const string Prefix = "dpapi:";

    public static string Protect(string plain) =>
        Prefix + Convert.ToBase64String(
            ProtectedData.Protect(Encoding.UTF8.GetBytes(plain), null, DataProtectionScope.CurrentUser));

    public static string Unprotect(string stored) =>
        stored.StartsWith(Prefix, StringComparison.Ordinal)
            ? Encoding.UTF8.GetString(ProtectedData.Unprotect(
                Convert.FromBase64String(stored[Prefix.Length..]), null, DataProtectionScope.CurrentUser))
            : stored;
}
```

```csharp
using Gdup.Auth;

namespace Gdup.Config;

/// <summary>Reads and writes remotes in gdup.conf; secrets are DPAPI-encrypted on save.</summary>
public sealed class ConfigStore(string path)
{
    public static string DefaultPath =>
        Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData), "gdup", "gdup.conf");

    public string FilePath { get; } = path;

    public IReadOnlyList<string> RemoteNames() => Read().Sections.Select(s => s.Name).ToList();

    public Remote? Load(string name)
    {
        var s = Read().Get(name);
        if (s is null) return null;
        var token = s["token"];
        return new Remote(
            s.Name,
            s["client_id"] ?? "",
            Dpapi.Unprotect(s["client_secret"] ?? ""),
            string.IsNullOrEmpty(s["scope"]) ? "drive" : s["scope"]!,
            s["root_folder_id"] ?? "",
            string.IsNullOrEmpty(token) ? null : OAuthToken.FromJson(Dpapi.Unprotect(token)));
    }

    public void Save(Remote remote)
    {
        var ini = Read();
        var s = ini.GetOrAdd(remote.Name);
        s["type"] = "drive";
        s["client_id"] = remote.ClientId;
        s["client_secret"] = remote.ClientSecret.Length == 0 ? "" : Dpapi.Protect(remote.ClientSecret);
        s["scope"] = remote.Scope;
        s["root_folder_id"] = remote.RootFolderId;
        s["token"] = remote.Token is null ? "" : Dpapi.Protect(remote.Token.ToJson());
        Write(ini);
    }

    public bool Delete(string name)
    {
        var ini = Read();
        if (!ini.Remove(name)) return false;
        Write(ini);
        return true;
    }

    private IniFile Read() =>
        File.Exists(FilePath) ? IniFile.Parse(File.ReadAllText(FilePath)) : new IniFile();

    private void Write(IniFile ini)
    {
        Directory.CreateDirectory(Path.GetDirectoryName(Path.GetFullPath(FilePath))!);
        var tmp = FilePath + ".tmp";
        File.WriteAllText(tmp, ini.ToString());
        File.Move(tmp, FilePath, overwrite: true);
    }
}
```

```csharp
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;

namespace Gdup.Auth;

public sealed class OAuthException(string error, string message) : Exception(message)
{
    public string Error { get; } = error;
}

/// <summary>Google OAuth 2.0 for installed apps: PKCE, auth URL, code exchange, refresh.</summary>
public static class GoogleOAuth
{
    public const string AuthEndpoint = "https://accounts.google.com/o/oauth2/v2/auth";
    public const string TokenEndpoint = "https://oauth2.googleapis.com/token";

    public static string ScopeUrl(string scope) => scope switch
    {
        "drive" => "https://www.googleapis.com/auth/drive",
        "drive.file" => "https://www.googleapis.com/auth/drive.file",
        _ => throw new ArgumentException($"Unsupported scope '{scope}'. Use drive or drive.file.", nameof(scope)),
    };

    public static (string Verifier, string Challenge) CreatePkce()
    {
        var verifier = Base64Url(RandomNumberGenerator.GetBytes(32));
        var challenge = Base64Url(SHA256.HashData(Encoding.ASCII.GetBytes(verifier)));
        return (verifier, challenge);
    }

    public static string BuildAuthUrl(string clientId, string redirectUri, string scope, string codeChallenge, string state)
    {
        var parameters = new Dictionary<string, string>
        {
            ["client_id"] = clientId,
            ["redirect_uri"] = redirectUri,
            ["response_type"] = "code",
            ["scope"] = ScopeUrl(scope),
            ["code_challenge"] = codeChallenge,
            ["code_challenge_method"] = "S256",
            ["state"] = state,
            ["access_type"] = "offline",
            ["prompt"] = "consent",
        };
        return AuthEndpoint + "?" + string.Join("&",
            parameters.Select(p => p.Key + "=" + Uri.EscapeDataString(p.Value)));
    }

    public static Task<OAuthToken> ExchangeCodeAsync(HttpClient http, string clientId, string clientSecret,
        string code, string verifier, string redirectUri, CancellationToken ct) =>
        PostTokenAsync(http, new Dictionary<string, string>
        {
            ["grant_type"] = "authorization_code",
            ["code"] = code,
            ["code_verifier"] = verifier,
            ["redirect_uri"] = redirectUri,
            ["client_id"] = clientId,
            ["client_secret"] = clientSecret,
        }, existingRefreshToken: null, ct);

    public static Task<OAuthToken> RefreshAsync(HttpClient http, string clientId, string clientSecret,
        string refreshToken, CancellationToken ct) =>
        PostTokenAsync(http, new Dictionary<string, string>
        {
            ["grant_type"] = "refresh_token",
            ["refresh_token"] = refreshToken,
            ["client_id"] = clientId,
            ["client_secret"] = clientSecret,
        }, refreshToken, ct);

    internal static string Base64Url(byte[] bytes) =>
        Convert.ToBase64String(bytes).TrimEnd('=').Replace('+', '-').Replace('/', '_');

    private static async Task<OAuthToken> PostTokenAsync(HttpClient http, Dictionary<string, string> form,
        string? existingRefreshToken, CancellationToken ct)
    {
        using var response = await http.PostAsync(TokenEndpoint, new FormUrlEncodedContent(form), ct);
        var body = await response.Content.ReadAsStringAsync(ct);
        var root = TryParseObject(body);

        if (!response.IsSuccessStatusCode)
        {
            var error = root is { } r1 && r1.TryGetProperty("error", out var e) ? e.GetString() ?? "unknown" : $"http_{(int)response.StatusCode}";
            var description = root is { } r2 && r2.TryGetProperty("error_description", out var d) ? d.GetString() : body;
            throw new OAuthException(error, $"Token request failed ({error}): {description}");
        }

        var json = root ?? throw new OAuthException("invalid_response", "Token endpoint returned a non-JSON body.");
        var refresh = json.TryGetProperty("refresh_token", out var rt) ? rt.GetString() : existingRefreshToken;
        return new OAuthToken(
            json.GetProperty("access_token").GetString()!,
            json.TryGetProperty("token_type", out var tt) ? tt.GetString() ?? "Bearer" : "Bearer",
            refresh ?? "",
            DateTimeOffset.UtcNow.AddSeconds(json.GetProperty("expires_in").GetInt32()));
    }

    private static JsonElement? TryParseObject(string body)
    {
        try
        {
            using var doc = JsonDocument.Parse(body);
            return doc.RootElement.ValueKind == JsonValueKind.Object ? doc.RootElement.Clone() : null;
        }
        catch (JsonException)
        {
            return null;
        }
    }
}
```

```csharp
using System.Collections.Specialized;
using System.Net;
using System.Net.Sockets;
using System.Security.Cryptography;
using System.Text;
using System.Web;

namespace Gdup.Auth;

/// <summary>
/// Installed-app sign-in: listens on 127.0.0.1:&lt;free port&gt;, sends the user to Google,
/// receives the redirect with the authorization code, and exchanges it (PKCE).
/// Uses a raw TcpListener so no http.sys URL reservation or admin rights are needed.
/// </summary>
public static class OAuthLoopback
{
    public static async Task<OAuthToken> AuthorizeAsync(HttpClient http, string clientId, string clientSecret,
        string scope, Action<string> openBrowser, CancellationToken ct)
    {
        using var listener = new TcpListener(IPAddress.Loopback, 0);
        listener.Start();
        var redirectUri = $"http://127.0.0.1:{((IPEndPoint)listener.LocalEndpoint).Port}/";
        var (verifier, challenge) = GoogleOAuth.CreatePkce();
        var state = GoogleOAuth.Base64Url(RandomNumberGenerator.GetBytes(16));

        openBrowser(GoogleOAuth.BuildAuthUrl(clientId, redirectUri, scope, challenge, state));

        while (true)
        {
            using var client = await listener.AcceptTcpClientAsync(ct);
            var stream = client.GetStream();
            var query = await ReadQueryAsync(stream, ct);
            if (query is null || (query["code"] is null && query["error"] is null))
            {
                await RespondAsync(stream, "404 Not Found", "Not found.", ct);
                continue;
            }
            if (query["state"] != state)
            {
                await RespondAsync(stream, "400 Bad Request", "Sign-in state did not match. Close this window and try again.", ct);
                throw new OAuthException("state_mismatch", "OAuth state mismatch; the sign-in response was not for this request.");
            }
            if (query["error"] is { } error)
            {
                await RespondAsync(stream, "200 OK", $"Sign-in failed: {error}. You can close this window.", ct);
                throw new OAuthException(error, $"Google sign-in failed: {error}");
            }
            await RespondAsync(stream, "200 OK", "gdup is signed in. You can close this window.", ct);
            return await GoogleOAuth.ExchangeCodeAsync(http, clientId, clientSecret, query["code"]!, verifier, redirectUri, ct);
        }
    }

    private static async Task<NameValueCollection?> ReadQueryAsync(NetworkStream stream, CancellationToken ct)
    {
        var buffer = new byte[8192];
        var total = 0;
        while (total < buffer.Length)
        {
            var n = await stream.ReadAsync(buffer.AsMemory(total), ct);
            if (n == 0) break;
            total += n;
            if (Encoding.ASCII.GetString(buffer, 0, total).Contains("\r\n\r\n")) break;
        }
        // Request line: GET /?state=...&code=... HTTP/1.1
        var parts = Encoding.ASCII.GetString(buffer, 0, total).Split("\r\n")[0].Split(' ');
        if (parts.Length < 2 || parts[0] != "GET") return null;
        var q = parts[1].IndexOf('?');
        return q < 0 ? null : HttpUtility.ParseQueryString(parts[1][(q + 1)..]);
    }

    private static async Task RespondAsync(NetworkStream stream, string status, string message, CancellationToken ct)
    {
        var body = Encoding.UTF8.GetBytes($"<html><body><p>{WebUtility.HtmlEncode(message)}</p></body></html>");
        var header = $"HTTP/1.1 {status}\r\nContent-Type: text/html; charset=utf-8\r\nContent-Length: {body.Length}\r\nConnection: close\r\n\r\n";
        await stream.WriteAsync(Encoding.ASCII.GetBytes(header), ct);
        await stream.WriteAsync(body, ct);
    }
}
```

```csharp
using Gdup.Config;

namespace Gdup.Auth;

public interface IAccessTokenSource
{
    Task<string> GetAccessTokenAsync(CancellationToken ct);
    Task<string> ForceRefreshAsync(CancellationToken ct);
}

public sealed class AuthExpiredException(string remoteName, Exception inner)
    : Exception($"Google rejected the saved sign-in for '{remoteName}'. Run: gdup config reconnect {remoteName}", inner);

/// <summary>Hands out access tokens, refreshing near expiry and persisting refreshed tokens.</summary>
public sealed class TokenProvider : IAccessTokenSource
{
    private static readonly TimeSpan RefreshMargin = TimeSpan.FromMinutes(5);
    private readonly SemaphoreSlim _lock = new(1, 1);
    private readonly HttpClient _http;
    private readonly Action<Remote> _persist;
    private Remote _remote;

    public TokenProvider(Remote remote, HttpClient http, Action<Remote> persist)
    {
        if (remote.Token is null)
            throw new ArgumentException($"Remote '{remote.Name}' is not signed in. Run: gdup config reconnect {remote.Name}", nameof(remote));
        _remote = remote;
        _http = http;
        _persist = persist;
    }

    public async Task<string> GetAccessTokenAsync(CancellationToken ct)
    {
        await _lock.WaitAsync(ct);
        try
        {
            var token = _remote.Token!;
            return token.Expiry - DateTimeOffset.UtcNow > RefreshMargin
                ? token.AccessToken
                : await RefreshLockedAsync(ct);
        }
        finally
        {
            _lock.Release();
        }
    }

    public async Task<string> ForceRefreshAsync(CancellationToken ct)
    {
        await _lock.WaitAsync(ct);
        try
        {
            return await RefreshLockedAsync(ct);
        }
        finally
        {
            _lock.Release();
        }
    }

    private async Task<string> RefreshLockedAsync(CancellationToken ct)
    {
        OAuthToken fresh;
        try
        {
            fresh = await GoogleOAuth.RefreshAsync(_http, _remote.ClientId, _remote.ClientSecret, _remote.Token!.RefreshToken, ct);
        }
        catch (OAuthException ex) when (ex.Error is "invalid_grant" or "invalid_client" or "unauthorized_client")
        {
            throw new AuthExpiredException(_remote.Name, ex);
        }
        _remote = _remote with { Token = fresh };
        _persist(_remote);
        return fresh.AccessToken;
    }
}
```

```csharp
using System.Net;
using System.Net.NetworkInformation;
using System.Net.Sockets;

namespace Gdup.Net;

public sealed record NicInfo(string Name, string Description, IReadOnlyList<IPAddress> Addresses, long SpeedBitsPerSecond);

public sealed class NicNotFoundException(string message) : Exception(message);

public static class NicSelector
{
    public static IReadOnlyList<NicInfo> ListUp() =>
        NetworkInterface.GetAllNetworkInterfaces()
            .Where(n => n.OperationalStatus == OperationalStatus.Up
                && n.NetworkInterfaceType is not (NetworkInterfaceType.Loopback or NetworkInterfaceType.Tunnel))
            .Select(n => new NicInfo(
                n.Name,
                n.Description,
                n.GetIPProperties().UnicastAddresses.Select(u => u.Address).ToList(),
                n.Speed))
            .ToList();

    public static (NicInfo Nic, IPAddress Address) Select(string via, IReadOnlyList<NicInfo> nics)
    {
        if (IPAddress.TryParse(via, out var ip))
        {
            var owner = nics.FirstOrDefault(n => n.Addresses.Contains(ip))
                ?? throw new NicNotFoundException($"No active network interface has the address {via}.");
            return (owner, ip);
        }

        var nic = nics.FirstOrDefault(n => string.Equals(n.Name, via, StringComparison.OrdinalIgnoreCase))
            ?? nics.FirstOrDefault(n => string.Equals(n.Description, via, StringComparison.OrdinalIgnoreCase))
            ?? throw new NicNotFoundException($"No active network interface is named '{via}'.");

        var address = nic.Addresses.FirstOrDefault(a => a.AddressFamily == AddressFamily.InterNetwork && !IsIPv4LinkLocal(a))
            ?? nic.Addresses.FirstOrDefault(a => a.AddressFamily == AddressFamily.InterNetworkV6 && !a.IsIPv6LinkLocal)
            ?? throw new NicNotFoundException($"Interface '{nic.Name}' has no routable IPv4 or IPv6 address.");
        return (nic, address);
    }

    private static bool IsIPv4LinkLocal(IPAddress address)
    {
        var b = address.GetAddressBytes();
        return b[0] == 169 && b[1] == 254;
    }
}
```

```csharp
using System.Net;
using System.Net.Sockets;

namespace Gdup.Net;

/// <summary>
/// Builds the single HttpClient used for a run. Every connection goes through ConnectCallback so we can
/// bind the socket to the --via interface's local IP (Windows then routes out of that NIC) and tune it
/// for one long, fast upload stream.
/// </summary>
public static class HttpClientFactory
{
    public const int SendBufferBytes = 8 * 1024 * 1024;

    public static HttpClient Create(IPAddress? bindAddress) => new(CreateHandler(bindAddress))
    {
        Timeout = Timeout.InfiniteTimeSpan,
        DefaultRequestVersion = HttpVersion.Version11,
        DefaultVersionPolicy = HttpVersionPolicy.RequestVersionExact,
    };

    public static SocketsHttpHandler CreateHandler(IPAddress? bindAddress) => new()
    {
        AllowAutoRedirect = false, // Drive answers 308 "Resume Incomplete"; it is not a redirect.
        AutomaticDecompression = DecompressionMethods.None,
        PooledConnectionLifetime = Timeout.InfiniteTimeSpan,
        PooledConnectionIdleTimeout = TimeSpan.FromMinutes(5),
        ConnectCallback = (context, ct) => ConnectAsync(context.DnsEndPoint, bindAddress, ct),
    };

    private static async ValueTask<Stream> ConnectAsync(DnsEndPoint endPoint, IPAddress? bindAddress, CancellationToken ct)
    {
        var addresses = await Dns.GetHostAddressesAsync(endPoint.Host, ct);
        if (bindAddress is not null)
            addresses = addresses.Where(a => a.AddressFamily == bindAddress.AddressFamily).ToArray();
        if (addresses.Length == 0)
            throw new HttpRequestException($"{endPoint.Host} has no {bindAddress?.AddressFamily} address usable from {bindAddress}.");

        Exception? last = null;
        foreach (var address in addresses)
        {
            var socket = new Socket(address.AddressFamily, SocketType.Stream, ProtocolType.Tcp)
            {
                NoDelay = true,
                SendBufferSize = SendBufferBytes,
            };
            try
            {
                if (bindAddress is not null) socket.Bind(new IPEndPoint(bindAddress, 0));
                await socket.ConnectAsync(new IPEndPoint(address, endPoint.Port), ct);
                return new NetworkStream(socket, ownsSocket: true);
            }
            catch (SocketException ex)
            {
                socket.Dispose();
                last = ex;
            }
            catch
            {
                socket.Dispose();
                throw;
            }
        }
        throw new HttpRequestException(
            $"Could not connect to {endPoint.Host}:{endPoint.Port}{(bindAddress is null ? "" : $" from {bindAddress}")}.", last);
    }
}
```

```csharp
using System.Text.Json;

namespace Gdup.Drive;

public sealed class DriveApiException(int statusCode, string reason, string message) : Exception(message)
{
    public int StatusCode { get; } = statusCode;
    public string Reason { get; } = reason;

    public bool IsTransient =>
        StatusCode >= 500
        || StatusCode == 429
        || (StatusCode == 403 && Reason is "rateLimitExceeded" or "userRateLimitExceeded");

    public static async Task<DriveApiException> FromResponseAsync(HttpResponseMessage response, CancellationToken ct)
    {
        var body = await response.Content.ReadAsStringAsync(ct);
        var reason = "";
        var message = body;
        try
        {
            using var doc = JsonDocument.Parse(body);
            var error = doc.RootElement.GetProperty("error");
            if (error.TryGetProperty("message", out var m)) message = m.GetString() ?? body;
            if (error.TryGetProperty("errors", out var errors) && errors.GetArrayLength() > 0
                && errors[0].TryGetProperty("reason", out var r))
                reason = r.GetString() ?? "";
        }
        catch (Exception ex) when (ex is JsonException or KeyNotFoundException or InvalidOperationException)
        {
            // Not a Google JSON error body; keep the raw text.
        }
        var status = (int)response.StatusCode;
        return new DriveApiException(status, reason, $"Drive API error {status} {reason}: {message}".Trim());
    }
}
```

```csharp
using System.Net;
using System.Net.Http.Headers;
using Gdup.Auth;

namespace Gdup.Drive;

internal static class DriveHttp
{
    /// <summary>Sends with a bearer token; on 401 refreshes once and resends a fresh request from the factory.</summary>
    public static async Task<HttpResponseMessage> SendAsync(HttpClient http, IAccessTokenSource tokens,
        Func<HttpRequestMessage> createRequest, HttpCompletionOption completion, CancellationToken ct)
    {
        var response = await SendOnceAsync(http, createRequest(), await tokens.GetAccessTokenAsync(ct), completion, ct);
        if (response.StatusCode != HttpStatusCode.Unauthorized) return response;

        response.Dispose();
        var refreshed = await tokens.ForceRefreshAsync(ct);
        return await SendOnceAsync(http, createRequest(), refreshed, completion, ct);
    }

    private static Task<HttpResponseMessage> SendOnceAsync(HttpClient http, HttpRequestMessage request,
        string accessToken, HttpCompletionOption completion, CancellationToken ct)
    {
        request.Headers.Authorization = new AuthenticationHeaderValue("Bearer", accessToken);
        return http.SendAsync(request, completion, ct);
    }
}
```

```csharp
using System.Text;
using System.Text.Json;
using Gdup.Auth;

namespace Gdup.Drive;

/// <summary>Drive v3 metadata calls: resolves "a/b/c" folder paths, creating missing folders.</summary>
public sealed class DriveClient(HttpClient http, IAccessTokenSource tokens, string apiBase = DriveClient.DefaultApiBase)
{
    public const string DefaultApiBase = "https://www.googleapis.com";
    private const string FolderMime = "application/vnd.google-apps.folder";

    public async Task<string> ResolveFolderAsync(string rootFolderId, string path, CancellationToken ct)
    {
        var parent = string.IsNullOrEmpty(rootFolderId) ? "root" : rootFolderId;
        var segments = path.Split(['/', '\\'], StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);
        foreach (var segment in segments)
            parent = await FindFolderAsync(parent, segment, ct) ?? await CreateFolderAsync(parent, segment, ct);
        return parent;
    }

    internal static string Escape(string value) => value.Replace("\\", "\\\\").Replace("'", "\\'");

    private async Task<string?> FindFolderAsync(string parentId, string name, CancellationToken ct)
    {
        var q = $"name = '{Escape(name)}' and '{Escape(parentId)}' in parents and mimeType = '{FolderMime}' and trashed = false";
        var url = $"{apiBase}/drive/v3/files?q={Uri.EscapeDataString(q)}&fields=files(id)&pageSize=10"
                  + "&supportsAllDrives=true&includeItemsFromAllDrives=true&corpora=allDrives";
        using var doc = await SendJsonAsync(() => new HttpRequestMessage(HttpMethod.Get, url), ct);
        var files = doc.RootElement.GetProperty("files");
        return files.GetArrayLength() == 0 ? null : files[0].GetProperty("id").GetString();
    }

    private async Task<string> CreateFolderAsync(string parentId, string name, CancellationToken ct)
    {
        var url = $"{apiBase}/drive/v3/files?fields=id&supportsAllDrives=true";
        var body = JsonSerializer.Serialize(new { name, mimeType = FolderMime, parents = new[] { parentId } });
        using var doc = await SendJsonAsync(() => new HttpRequestMessage(HttpMethod.Post, url)
        {
            Content = new StringContent(body, Encoding.UTF8, "application/json"),
        }, ct);
        return doc.RootElement.GetProperty("id").GetString()!;
    }

    private async Task<JsonDocument> SendJsonAsync(Func<HttpRequestMessage> createRequest, CancellationToken ct)
    {
        using var response = await DriveHttp.SendAsync(http, tokens, createRequest, HttpCompletionOption.ResponseContentRead, ct);
        if (!response.IsSuccessStatusCode) throw await DriveApiException.FromResponseAsync(response, ct);
        return JsonDocument.Parse(await response.Content.ReadAsStringAsync(ct));
    }
}
```

```csharp
namespace Gdup.Drive;

public static class ResumeOffset
{
    /// <summary>Drive's 308 carries "Range: bytes=0-N" for the committed prefix; no header means nothing is committed.</summary>
    public static long FromResponse(HttpResponseMessage response) =>
        response.Headers.TryGetValues("Range", out var values) ? Parse(values.FirstOrDefault()) : 0;

    public static long Parse(string? rangeHeader)
    {
        if (string.IsNullOrWhiteSpace(rangeHeader)) return 0;
        var dash = rangeHeader.LastIndexOf('-');
        if (!rangeHeader.StartsWith("bytes=", StringComparison.OrdinalIgnoreCase)
            || dash < 0
            || !long.TryParse(rangeHeader.AsSpan(dash + 1), out var lastByte))
            throw new FormatException($"Unexpected Range header '{rangeHeader}'.");
        return lastByte + 1;
    }
}
```

```csharp
using System.Buffers;

namespace Gdup.Drive;

public sealed class LocalFileChangedException(string message) : Exception(message);

/// <summary>Streams one byte range of a file straight to the socket; nothing is buffered beyond one read.</summary>
public sealed class FileRangeContent(string path, long offset, long length, Action<long> onBytesSent) : HttpContent
{
    public const int BufferSize = 4 * 1024 * 1024;

    protected override Task SerializeToStreamAsync(Stream stream, TransportContext? context) =>
        SerializeToStreamAsync(stream, context, CancellationToken.None);

    protected override async Task SerializeToStreamAsync(Stream stream, TransportContext? context, CancellationToken ct)
    {
        await using var file = new FileStream(path, FileMode.Open, FileAccess.Read, FileShare.ReadWrite,
            bufferSize: 1, FileOptions.Asynchronous | FileOptions.SequentialScan);
        file.Position = offset;
        var buffer = ArrayPool<byte>.Shared.Rent(BufferSize);
        try
        {
            var remaining = length;
            while (remaining > 0)
            {
                var read = await file.ReadAsync(buffer.AsMemory(0, (int)Math.Min(BufferSize, remaining)), ct);
                if (read == 0)
                    throw new LocalFileChangedException($"{path} ended {remaining} bytes early; the file changed during upload.");
                await stream.WriteAsync(buffer.AsMemory(0, read), ct);
                remaining -= read;
                onBytesSent(read);
            }
        }
        finally
        {
            ArrayPool<byte>.Shared.Return(buffer);
        }
    }

    protected override bool TryComputeLength(out long computedLength)
    {
        computedLength = length;
        return true;
    }
}
```

```csharp
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;

namespace Gdup.Drive;

public sealed record SessionState(
    string SessionUri,
    string FilePath,
    long Size,
    long MtimeTicks,
    string Remote,
    string FolderId,
    string Name,
    long ChunkSize,
    DateTimeOffset Created);

/// <summary>Persists resumable session URIs so an upload survives the process being killed.</summary>
public sealed class SessionStore(string directory)
{
    public static string DefaultDirectory =>
        Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "gdup", "sessions");

    public static string KeyFor(string fullPath, long size, long mtimeTicks, string remote, string folderId, string name)
    {
        var raw = string.Join("|", fullPath.ToUpperInvariant(), size, mtimeTicks, remote, folderId, name);
        return Convert.ToHexStringLower(SHA256.HashData(Encoding.UTF8.GetBytes(raw)));
    }

    public SessionState? Load(string key)
    {
        var path = PathFor(key);
        return File.Exists(path) ? JsonSerializer.Deserialize<SessionState>(File.ReadAllText(path)) : null;
    }

    public void Save(string key, SessionState state)
    {
        Directory.CreateDirectory(directory);
        var tmp = PathFor(key) + ".tmp";
        File.WriteAllText(tmp, JsonSerializer.Serialize(state));
        File.Move(tmp, PathFor(key), overwrite: true);
    }

    public void Delete(string key)
    {
        var path = PathFor(key);
        if (File.Exists(path)) File.Delete(path);
    }

    public IReadOnlyList<(string Key, SessionState State)> List()
    {
        if (!Directory.Exists(directory)) return [];
        var entries = new List<(string Key, SessionState State)>();
        foreach (var path in Directory.GetFiles(directory, "*.json"))
        {
            try
            {
                if (JsonSerializer.Deserialize<SessionState>(File.ReadAllText(path)) is { } state)
                    entries.Add((Path.GetFileNameWithoutExtension(path), state));
            }
            catch (JsonException)
            {
                // Corrupt state file: ignore it; the upload will simply start a new session.
            }
        }
        return entries.OrderBy(e => e.State.Created).ToList();
    }

    /// <summary>Drops state for the same destination left over from an older version of the file.</summary>
    public void DeleteOtherVersions(string keepKey, string fullPath, string remote, string folderId, string name)
    {
        foreach (var (key, state) in List())
        {
            if (key != keepKey
                && string.Equals(state.FilePath, fullPath, StringComparison.OrdinalIgnoreCase)
                && state.Remote == remote && state.FolderId == folderId && state.Name == name)
                Delete(key);
        }
    }

    private string PathFor(string key) => Path.Combine(directory, key + ".json");
}
```

```csharp
using System.Net;
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;

namespace Gdup.Tests.Drive;

public enum Fault
{
    None,
    Status503,
    Status429,
    Status401,
    QuotaExceeded,
    CommitHalfThenReset,
    Stall,
    Expire,
    CancelClient,
}

/// <summary>In-process imitation of Drive's resumable upload protocol with scripted per-chunk faults.</summary>
public sealed class FakeDriveServer : HttpMessageHandler
{
    public const string UploadBase = "https://fake.local";

    private readonly MemoryStream _committed = new();
    private string? _activeSession;
    private long _total;

    public Queue<Fault> ChunkFaults { get; } = new();
    public int SessionsStarted { get; private set; }
    public int StatusQueries { get; private set; }
    public List<string> AuthHeaders { get; } = [];
    public string? UploadedName { get; private set; }
    public string? UploadedContentType { get; private set; }
    public Action? OnCancelClient { get; set; }
    public byte[] Committed => _committed.ToArray();

    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken ct)
    {
        AuthHeaders.Add(request.Headers.Authorization?.ToString() ?? "");
        var url = request.RequestUri!.AbsoluteUri;
        if (request.Method == HttpMethod.Post && url.StartsWith($"{UploadBase}/upload/drive/v3/files?uploadType=resumable"))
            return await StartSessionAsync(request, ct);
        if (request.Method == HttpMethod.Put)
            return await PutAsync(request, url, ct);
        return new HttpResponseMessage(HttpStatusCode.NotFound);
    }

    private async Task<HttpResponseMessage> StartSessionAsync(HttpRequestMessage request, CancellationToken ct)
    {
        using var metadata = JsonDocument.Parse(await request.Content!.ReadAsStringAsync(ct));
        UploadedName = metadata.RootElement.GetProperty("name").GetString();
        UploadedContentType = request.Headers.GetValues("X-Upload-Content-Type").Single();
        _total = long.Parse(request.Headers.GetValues("X-Upload-Content-Length").Single());
        _committed.SetLength(0);
        _activeSession = $"{UploadBase}/upload/drive/v3/files?uploadType=resumable&upload_id={++SessionsStarted}";
        var response = new HttpResponseMessage(HttpStatusCode.OK);
        response.Headers.Location = new Uri(_activeSession);
        return response;
    }

    private async Task<HttpResponseMessage> PutAsync(HttpRequestMessage request, string url, CancellationToken ct)
    {
        if (url != _activeSession) return new HttpResponseMessage(HttpStatusCode.Gone);

        var range = request.Content?.Headers.ContentRange;
        if (range is null || !range.HasRange)
        {
            StatusQueries++;
            return Progress();
        }

        var fault = ChunkFaults.Count > 0 ? ChunkFaults.Dequeue() : Fault.None;
        switch (fault)
        {
            case Fault.Status503:
                await request.Content!.ReadAsByteArrayAsync(ct);
                return new HttpResponseMessage(HttpStatusCode.ServiceUnavailable);
            case Fault.Status429:
                await request.Content!.ReadAsByteArrayAsync(ct);
                return new HttpResponseMessage(HttpStatusCode.TooManyRequests);
            case Fault.Status401:
                return new HttpResponseMessage(HttpStatusCode.Unauthorized);
            case Fault.QuotaExceeded:
                return new HttpResponseMessage(HttpStatusCode.Forbidden)
                {
                    Content = new StringContent(
                        """{"error":{"code":403,"message":"Quota exceeded","errors":[{"reason":"storageQuotaExceeded"}]}}""",
                        Encoding.UTF8, "application/json"),
                };
            case Fault.Stall:
                await Task.Delay(Timeout.Infinite, ct);
                break;
            case Fault.CancelClient:
                OnCancelClient?.Invoke();
                await Task.Delay(Timeout.Infinite, ct);
                break;
            case Fault.Expire:
                _activeSession = null;
                _committed.SetLength(0);
                return new HttpResponseMessage(HttpStatusCode.Gone);
        }

        var body = await request.Content!.ReadAsByteArrayAsync(ct);
        if (range.From != _committed.Length || range.Length != _total || body.Length != range.To - range.From + 1)
            return new HttpResponseMessage(HttpStatusCode.BadRequest)
            {
                Content = new StringContent($"bad range {range} (committed {_committed.Length}, body {body.Length})"),
            };

        if (fault == Fault.CommitHalfThenReset)
        {
            _committed.Write(body, 0, body.Length / 2);
            throw new HttpRequestException("Connection reset by fake server");
        }

        _committed.Write(body);
        return Progress();
    }

    private HttpResponseMessage Progress()
    {
        if (_committed.Length == _total)
        {
            var json = JsonSerializer.Serialize(new
            {
                id = "file-1",
                name = UploadedName,
                size = _total.ToString(),
                md5Checksum = Convert.ToHexStringLower(MD5.HashData(Committed)),
            });
            return new HttpResponseMessage(HttpStatusCode.OK) { Content = new StringContent(json, Encoding.UTF8, "application/json") };
        }
        var response = new HttpResponseMessage((HttpStatusCode)308);
        if (_committed.Length > 0)
            response.Headers.TryAddWithoutValidation("Range", $"bytes=0-{_committed.Length - 1}");
        return response;
    }
}
```

```csharp
using System.Net.Http.Headers;

namespace Gdup.Drive;

public sealed record UploadRequest(string FilePath, string RemoteName, string FolderId, string Name, long ChunkSize, TimeSpan StallTimeout);

public sealed record UploadResult(string FileId, string Name, long Size, string? DriveMd5, string LocalMd5)

    /// <summary>null when Drive did not report a checksum.</summary>
    public bool? Md5Matches => DriveMd5 is null ? null : string.Equals(DriveMd5, LocalMd5, StringComparison.OrdinalIgnoreCase);
}

public interface IUploadProgress
{
    void Start(long totalBytes);

    /// <summary>Bytes of the file sent so far; moves backwards when a retry resumes from Drive's committed offset.</summary>
    void Position(long bytes);

    void Event(string message);
}

/// <summary>
/// Drive v3 resumable upload over one stream: chunks are sent strictly in order, and after any
/// failure Drive is asked for its committed offset before continuing.
/// </summary>
public sealed class ResumableUploader(
    HttpClient http,
    IAccessTokenSource tokens,
    SessionStore sessions,
    IUploadProgress progress,
    string uploadBase = DriveClient.DefaultApiBase,
    Func<TimeSpan, CancellationToken, Task>? delay = null)
{
    private const double MaxBackoffSeconds = 64;
    private readonly Func<TimeSpan, CancellationToken, Task> _delay = delay ?? Task.Delay;

    public async Task<UploadResult> UploadAsync(UploadRequest request, CancellationToken ct)
    {
        var file = new FileInfo(request.FilePath);
        if (!file.Exists) throw new FileNotFoundException($"File not found: {file.FullName}", file.FullName);
        var size = file.Length;
        var mtime = file.LastWriteTimeUtc.Ticks;
        var key = SessionStore.KeyFor(file.FullName, size, mtime, request.RemoteName, request.FolderId, request.Name);
        sessions.DeleteOtherVersions(key, file.FullName, request.RemoteName, request.FolderId, request.Name);

        using var hashCts = CancellationTokenSource.CreateLinkedTokenSource(ct);
        var md5Task = ComputeMd5Async(file.FullName, hashCts.Token);
        progress.Start(size);

        var sessionUri = sessions.Load(key)?.SessionUri;
        var attempt = 0;
        DriveFile? done = null;
        try
        {
            while (done is null)
            {
                try
                {
                    Step step;
                    if (sessionUri is null)
                    {
                        sessionUri = await StartSessionAsync(request, size, ct);
                        sessions.Save(key, new SessionState(sessionUri, file.FullName, size, mtime, request.RemoteName,
                            request.FolderId, request.Name, request.ChunkSize, DateTimeOffset.UtcNow));
                        step = Step.At(0);
                    }
                    else
                    {
                        step = await QueryAsync(sessionUri, size, request.StallTimeout, ct);
                    }

                    while (step is { Completed: null, Expired: false })
                    {
                        progress.Position(step.Offset);
                        var length = Math.Min(request.ChunkSize, size - step.Offset);
                        step = await SendChunkAsync(sessionUri, file.FullName, step.Offset, length, size, request.StallTimeout, ct);
                        attempt = 0;
                    }

                    if (step.Expired)
                    {
                        progress.Event("Drive discarded the upload session; starting a new one from the beginning.");
                        sessions.Delete(key);
                        sessionUri = null;
                        continue;
                    }

                    done = step.Completed;
                }
                catch (Exception ex) when (!ct.IsCancellationRequested && IsTransient(ex))
                {
                    attempt++;
                    var wait = Backoff(attempt);
                    progress.Event($"Retry {attempt} in {wait.TotalSeconds:0.#}s: {ex.Message}");
                    await _delay(wait, ct);
                }
            }

            progress.Position(size);
            sessions.Delete(key);
            var localMd5 = await md5Task;
            return new UploadResult(done.Id, done.Name, done.Size >= 0 ? done.Size : size, done.Md5, localMd5);
        }
        finally
        {
            await hashCts.CancelAsync();
        }
    }

    private async Task<string> StartSessionAsync(UploadRequest request, long size, CancellationToken ct)
    {
        var url = $"{uploadBase}/upload/drive/v3/files?uploadType=resumable&supportsAllDrives=true&fields=id,name,size,md5Checksum";
        var metadata = JsonSerializer.Serialize(new { name = request.Name, parents = new[] { request.FolderId } });
        using var timeout = CancellationTokenSource.CreateLinkedTokenSource(ct);
        timeout.CancelAfter(request.StallTimeout);

        using var response = await DriveHttp.SendAsync(http, tokens, () =>
        {
            var message = new HttpRequestMessage(HttpMethod.Post, url)
            {
                Content = new StringContent(metadata, Encoding.UTF8, "application/json"),
            };
            message.Headers.Add("X-Upload-Content-Type", ContentTypes.For(request.Name));
            message.Headers.Add("X-Upload-Content-Length", size.ToString(CultureInfo.InvariantCulture));
            return message;
        }, HttpCompletionOption.ResponseContentRead, timeout.Token);

        if (!response.IsSuccessStatusCode) throw await DriveApiException.FromResponseAsync(response, ct);
        return response.Headers.Location?.AbsoluteUri
            ?? throw new DriveApiException((int)response.StatusCode, "noLocation", "Drive did not return an upload session URI.");
    }

    private async Task<Step> QueryAsync(string sessionUri, long size, TimeSpan stallTimeout, CancellationToken ct)
    {
        using var timeout = CancellationTokenSource.CreateLinkedTokenSource(ct);
        timeout.CancelAfter(stallTimeout);
        using var response = await DriveHttp.SendAsync(http, tokens, () =>
        {
            var content = new ByteArrayContent([]);
            content.Headers.ContentRange = new ContentRangeHeaderValue(size); // bytes */size
            return new HttpRequestMessage(HttpMethod.Put, sessionUri) { Content = content };
        }, HttpCompletionOption.ResponseContentRead, timeout.Token);
        return await InterpretAsync(response, ct);
    }

    private async Task<Step> SendChunkAsync(string sessionUri, string path, long offset, long length, long size,
        TimeSpan stallTimeout, CancellationToken ct)
    {
        using var stallCts = CancellationTokenSource.CreateLinkedTokenSource(ct);
        var clock = new ActivityClock();
        var watchdog = WatchAsync(clock, stallTimeout, stallCts);
        try
        {
            using var response = await DriveHttp.SendAsync(http, tokens, () =>
            {
                clock.Touch();
                if (length == 0) // zero-byte file: an empty PUT completes the upload
                    return new HttpRequestMessage(HttpMethod.Put, sessionUri) { Content = new ByteArrayContent([]) };

                var position = offset;
                var content = new FileRangeContent(path, offset, length, sent =>
                {
                    clock.Touch();
                    position += sent;
                    progress.Position(position);
                });
                content.Headers.ContentRange = new ContentRangeHeaderValue(offset, offset + length - 1, size);
                return new HttpRequestMessage(HttpMethod.Put, sessionUri) { Content = content };
            }, HttpCompletionOption.ResponseContentRead, stallCts.Token);
            return await InterpretAsync(response, ct);
        }
        catch (OperationCanceledException) when (!ct.IsCancellationRequested)
        {
            throw new TimeoutException($"No upload progress for {stallTimeout.TotalSeconds:0.#} s; reconnecting.");
        }
        finally
        {
            await stallCts.CancelAsync();
            await watchdog;
        }
    }

    private static async Task<Step> InterpretAsync(HttpResponseMessage response, CancellationToken ct)
    {
        switch ((int)response.StatusCode)
        {
            case 200 or 201:
                return Step.Done(await ParseFileAsync(response, ct));
            case 308:
                return Step.At(ResumeOffset.FromResponse(response));
            case 404 or 410:
                return Step.Gone;
            default:
                throw await DriveApiException.FromResponseAsync(response, ct);
        }
    }

    private static async Task<DriveFile> ParseFileAsync(HttpResponseMessage response, CancellationToken ct)
    {
        using var doc = JsonDocument.Parse(await response.Content.ReadAsStringAsync(ct));
        var r = doc.RootElement;
        return new DriveFile(
            r.GetProperty("id").GetString()!,
            r.TryGetProperty("name", out var n) ? n.GetString() ?? "" : "",
            r.TryGetProperty("size", out var s) && long.TryParse(s.GetString(), out var parsed) ? parsed : -1,
            r.TryGetProperty("md5Checksum", out var m) ? m.GetString() : null);
    }

    private static bool IsTransient(Exception ex)
    {
        for (var e = ex; e is not null; e = e.InnerException)
        {
            if (e is LocalFileChangedException or FileNotFoundException or DirectoryNotFoundException or UnauthorizedAccessException)
                return false;
        }
        return ex switch
        {
            DriveApiException api => api.IsTransient,
            HttpRequestException or IOException or TimeoutException or OperationCanceledException => true,
            _ => false,
        };
    }

    private static TimeSpan Backoff(int attempt)
    {
        var cap = Math.Min(MaxBackoffSeconds, Math.Pow(2, attempt));
        return TimeSpan.FromSeconds(cap / 2 + Random.Shared.NextDouble() * cap / 2);
    }

    private static Task<string> ComputeMd5Async(string path, CancellationToken ct) => Task.Run(async () =>
    {
        await using var stream = new FileStream(path, FileMode.Open, FileAccess.Read, FileShare.ReadWrite,
            FileRangeContent.BufferSize, FileOptions.Asynchronous | FileOptions.SequentialScan);
        return Convert.ToHexStringLower(await MD5.HashDataAsync(stream, ct));
    }, ct);

    private static async Task WatchAsync(ActivityClock clock, TimeSpan stallTimeout, CancellationTokenSource stallCts)
    {
        var tick = TimeSpan.FromMilliseconds(Math.Clamp(stallTimeout.TotalMilliseconds / 4, 10, 1000));
        try
        {
            while (!stallCts.IsCancellationRequested)
            {
                await Task.Delay(tick, stallCts.Token);
                if (clock.Idle > stallTimeout)
                {
                    await stallCts.CancelAsync();
                    return;
                }
            }
        }
        catch (OperationCanceledException)
        {
            // Chunk finished or was cancelled.
        }
    }

    private sealed class ActivityClock
    {
        private long _last = Stopwatch.GetTimestamp();

        public TimeSpan Idle => Stopwatch.GetElapsedTime(Interlocked.Read(ref _last));

        public void Touch() => Interlocked.Exchange(ref _last, Stopwatch.GetTimestamp());
    }

    private sealed record DriveFile(string Id, string Name, long Size, string? Md5);

    private readonly record struct Step(long Offset, DriveFile? Completed, bool Expired)
    {
        public static readonly Step Gone = new(0, null, true);

        public static Step At(long offset) => new(offset, null, false);

        public static Step Done(DriveFile file) => new(0, file, false);
    }
}
```

```csharp
    public static string Bytes(double bytes)
    {
        var unit = 0;

        {

            unit++;
        }
        return unit == 0 ? $"{bytes:0} B" : $"{bytes:0.0} {Units[unit]}";
```

```csharp
namespace Gdup.Output;

/// <summary>Transfer rate over the most recent <c>window</c> of (time, position) samples.</summary>
public sealed class RateWindow(TimeSpan window)
{
    private readonly Queue<(double Seconds, long Position)> _samples = new();
    private (double Seconds, long Position) _last;

    public double BytesPerSecond
    {
        get
        {
            if (_samples.Count < 2) return 0;
            var first = _samples.Peek();
            var elapsed = _last.Seconds - first.Seconds;
            return elapsed <= 0 ? 0 : Math.Max(0, (_last.Position - first.Position) / elapsed);
        }
    }

    public void Add(double seconds, long position)
    {
        _last = (seconds, position);
        _samples.Enqueue(_last);
        while (_samples.Count > 2 && seconds - _samples.Peek().Seconds > window.TotalSeconds)
            _samples.Dequeue();
    }

    public void Reset() => _samples.Clear();
}
```

```csharp
using System.Diagnostics;
using Gdup.Drive;

namespace Gdup.Output;

/// <summary>
/// Interactive: one line redrawn in place about 4 times a second.
/// Redirected: a plain line every 10 seconds. Events always get their own line.
/// </summary>
public sealed class ProgressReporter(string fileName, string via, TextWriter output, bool interactive) : IUploadProgress
{
    private readonly object _gate = new();
    private readonly Stopwatch _clock = Stopwatch.StartNew();
    private readonly RateWindow _window = new(TimeSpan.FromSeconds(5));
    private readonly TimeSpan _interval = interactive ? TimeSpan.FromMilliseconds(250) : TimeSpan.FromSeconds(10);
    private long _total;
    private long _position;
    private long _startPosition;
    private bool _started;
    private TimeSpan _nextDraw = TimeSpan.Zero;
    private int _lastLength;

    public double AverageBytesPerSecond
    {
        get
        {
            lock (_gate)
            {
                var seconds = _clock.Elapsed.TotalSeconds;
                return seconds > 0 ? (_position - _startPosition) / seconds : 0;
            }
        }
    }

    public void Start(long totalBytes)
    {
        lock (_gate) _total = totalBytes;
    }

    public void Position(long bytes)
    {
        lock (_gate)
        {
            if (!_started)
            {
                _startPosition = bytes;
                _started = true;
            }
            if (bytes < _position) _window.Reset();
            _position = bytes;
            var now = _clock.Elapsed;
            _window.Add(now.TotalSeconds, bytes);
            if (now >= _nextDraw)
            {
                _nextDraw = now + _interval;
                Draw(now);
            }
        }
    }

    public void Event(string message)
    {
        lock (_gate)
        {
            ClearLine();
            output.WriteLine(message);
            _nextDraw = TimeSpan.Zero;
        }
    }

    public void Complete()
    {
        lock (_gate)
        {
            Draw(_clock.Elapsed);
            if (interactive)
            {
                output.WriteLine();
                _lastLength = 0;
            }
        }
    }

    internal string Line(TimeSpan now)
    {
        var percent = _total == 0 ? 100 : _position * 100.0 / _total;
        var rate = _window.BytesPerSecond;
        var average = now.TotalSeconds > 0 ? (_position - _startPosition) / now.TotalSeconds : 0;
        var eta = rate > 0 ? Format.Duration(TimeSpan.FromSeconds((_total - _position) / rate)) : "--:--:--";
        var suffix = via.Length > 0 ? $"  via {via}" : "";
        return $"{fileName}  {percent:0.0}%  {Format.Bytes(_position)}/{Format.Bytes(_total)}  "
             + $"{Format.Rate(rate)} (avg {Format.Rate(average)})  ETA {eta}{suffix}";
    }

    private void Draw(TimeSpan now)
    {
        var line = Line(now);
        if (interactive)
        {
            output.Write("\r" + line.PadRight(_lastLength));
            _lastLength = line.Length;
        }
        else
        {
            output.WriteLine(line);
        }
    }

    private void ClearLine()
    {
        if (!interactive || _lastLength == 0) return;
        output.Write("\r" + new string(' ', _lastLength) + "\r");
        _lastLength = 0;
    }
}
```

```csharp
using System.Globalization;

namespace Gdup.Cli;

public static class SizeParser
{
    public const long Quantum = 256 * 1024;
    public const long MaxChunk = 4L * 1024 * 1024 * 1024;

    /// <summary>Parses sizes like 256M, 512K, 1G, 256MB or plain bytes (binary multiples).</summary>
    public static long ParseChunkSize(string text)
    {
        var t = text.Trim().ToUpperInvariant();
        if (t.Length > 1 && t.EndsWith('B') && char.IsLetter(t[^2])) t = t[..^1];

        long multiplier = 1;
        if (t.Length > 0 && char.IsLetter(t[^1]))
        {
            multiplier = t[^1] switch
            {
                'K' => 1024L,
                'M' => 1024L * 1024,
                'G' => 1024L * 1024 * 1024,
                _ => throw new UsageException($"Unknown size suffix in '{text}'. Use K, M or G."),
            };
            t = t[..^1];
        }

        if (!long.TryParse(t, NumberStyles.None, CultureInfo.InvariantCulture, out var number) || number <= 0)
            throw new UsageException($"Invalid size '{text}'.");
        if (number > MaxChunk / multiplier)
            throw new UsageException($"Chunk size must be at most 4G; got {text}.");

        var bytes = number * multiplier;
        if (bytes % Quantum != 0)
            throw new UsageException($"Chunk size must be a multiple of 256K; got {text}.");
        return bytes;
    }
}
```

```csharp
using Gdup.Config;
using Gdup.Net;

namespace Gdup.Cli;

public static class ExitCodes
{
    public const int Ok = 0;
    public const int Usage = 1;
    public const int Failed = 2;
    public const int ChecksumMismatch = 3;
}

/// <summary>Runs a command body and turns exceptions into messages and exit codes.</summary>
public static class CliRunner
{
    public static async Task<int> RunAsync(Func<Task<int>> body, CancellationToken ct, TextWriter? error = null)
    {
        error ??= Console.Error;
        try
        {
            return await body();
        }
        catch (OperationCanceledException) when (ct.IsCancellationRequested)
        {
            error.WriteLine();
            error.WriteLine("Cancelled. Run the same command again, or `gdup resume`, to continue where it stopped.");
            return ExitCodes.Failed;
        }
        catch (Exception ex) when (ex is UsageException or NicNotFoundException or RcloneConfigEncryptedException)
        {
            error.WriteLine($"error: {ex.Message}");
            return ExitCodes.Usage;
        }
        catch (Exception ex)
        {
            error.WriteLine($"error: {Describe(ex)}");
            return ExitCodes.Failed;
        }
    }

    internal static string Describe(Exception ex)
    {
        var messages = new List<string>();
        for (var e = ex; e is not null; e = e.InnerException)
        {
            if (!messages.Contains(e.Message)) messages.Add(e.Message);
        }
        return string.Join(" -> ", messages);
    }
}
```

```csharp
namespace Gdup.Cli;

internal static class Prompt
{
    public static string Ask(string label, string? defaultValue = null)
    {
        Console.Write(string.IsNullOrEmpty(defaultValue) ? $"{label}: " : $"{label} [{defaultValue}]: ");
        var line = Console.ReadLine() ?? throw new UsageException("Input ended before the question was answered.");
        line = line.Trim();
        return line.Length == 0 ? defaultValue ?? "" : line;
    }

    public static string AskRequired(string label, string? defaultValue = null)
    {
        while (true)
        {
            var value = Ask(label, defaultValue);
            if (value.Length > 0) return value;
            Console.WriteLine("  A value is required.");
        }
    }

    /// <summary>Asks for a secret without echoing the current one; Enter keeps the current value.</summary>
    public static string AskSecret(string label, string current)
    {
        while (true)
        {
            var value = Ask(current.Length > 0 ? $"{label} (Enter keeps current)" : label);
            if (value.Length > 0) return value;
            if (current.Length > 0) return current;
            Console.WriteLine("  A value is required.");
        }
    }

    public static bool Confirm(string question, bool defaultYes = false)
    {
        var answer = Ask($"{question} ({(defaultYes ? "Y/n" : "y/N")})");
        return answer.Length == 0 ? defaultYes : answer.StartsWith('y') || answer.StartsWith('Y');
    }

    public static T Choose<T>(string label, IReadOnlyList<T> items, Func<T, string> describe)
    {
        for (var i = 0; i < items.Count; i++)
            Console.WriteLine($"  {i + 1}) {describe(items[i])}");
        while (true)
        {
            if (int.TryParse(Ask(label), out var n) && n >= 1 && n <= items.Count) return items[n - 1];
            Console.WriteLine($"  Enter a number from 1 to {items.Count}.");
        }
    }
}
```

```csharp
    private static ConfigStore Store() => new(ConfigStore.DefaultPath);

    private static async Task<int> WizardAsync(CancellationToken ct)
    {
        var store = Store();
        while (true)
        {
            var names = store.RemoteNames();
            Console.WriteLine();
            Console.WriteLine(names.Count == 0 ? "No remotes configured." : "Remotes: " + string.Join(", ", names));
            Console.WriteLine("n) New remote   e) Edit remote   d) Delete remote   q) Quit");
            switch (Prompt.Ask("choice").ToLowerInvariant())
            {
                case "n":
                    await NewRemoteAsync(store, ct);
                    break;
                case "e" when names.Count > 0:

                    break;

                    break;
                case "q":
                    return ExitCodes.Ok;
            }
        }

    private static async Task NewRemoteAsync(ConfigStore store, CancellationToken ct)
    {
        string name;
        while (true)
        {
            name = Prompt.AskRequired("Name for the new remote");
            if (name.IndexOfAny([':', '[', ']']) >= 0) Console.WriteLine("  Names cannot contain ':', '[' or ']'.");
            else if (store.Load(name) is not null) Console.WriteLine($"  Remote '{name}' already exists.");
            else break;
        }
        Console.WriteLine(ClientHelp);
        var remote = new Remote(
            name,
            Prompt.AskRequired("Client ID"),
            Prompt.AskRequired("Client secret"),
            AskScope("drive"),
            Prompt.Ask("Root folder ID (blank = My Drive)"),
            Token: null);
        store.Save(await SignInAsync(remote, ct));
        Console.WriteLine($"Remote '{name}' saved to {store.FilePath}");

    private static async Task EditRemoteAsync(ConfigStore store, string name, CancellationToken ct)
    {
        var current = store.Load(name)!;
        var root = Prompt.Ask("Root folder ID (blank keeps current, '-' clears)", current.RootFolderId);
        var edited = current with
        {
            ClientId = Prompt.AskRequired("Client ID", current.ClientId),
            ClientSecret = Prompt.AskSecret("Client secret", current.ClientSecret),
            Scope = AskScope(current.Scope),
            RootFolderId = root == "-" ? "" : root,
        };
        var credentialsChanged = edited.ClientId != current.ClientId
            || edited.ClientSecret != current.ClientSecret
            || edited.Scope != current.Scope;
        if (credentialsChanged || edited.Token is null || Prompt.Confirm("Sign in again?"))
            edited = await SignInAsync(edited with { Token = null }, ct);
        store.Save(edited);
        Console.WriteLine($"Remote '{name}' saved.");

    private static string AskScope(string current)
    {
        while (true)
        {
            var scope = Prompt.Ask("Scope (drive or drive.file)", current);
            if (scope is "drive" or "drive.file") return scope;
            Console.WriteLine("  Enter drive or drive.file.");
        }

    private static int Show(string? name)
    {
        var store = Store();
        IReadOnlyList<string> names = name is null ? store.RemoteNames() : new[] { name };
        if (names.Count == 0)
        {
            Console.WriteLine($"No remotes in {store.FilePath}. Run: gdup config");
            return ExitCodes.Ok;
        }
        foreach (var n in names)
        {
            var r = store.Load(n) ?? throw new UsageException($"Remote '{n}' not found in {store.FilePath}.");
            var token = r.Token is null
                ? "not signed in"
                : $"signed in (access token expires {r.Token.Expiry.ToLocalTime():yyyy-MM-dd HH:mm})";
            Console.WriteLine($"[{r.Name}]");
            Console.WriteLine($"client_id      = {r.ClientId}");
            Console.WriteLine($"client_secret  = {(r.ClientSecret.Length > 0 ? "****" : "")}");
            Console.WriteLine($"scope          = {r.Scope}");
            Console.WriteLine($"root_folder_id = {r.RootFolderId}");
            Console.WriteLine($"token          = {token}");
            Console.WriteLine();
        }
        return ExitCodes.Ok;
    }

    private static async Task<int> ReconnectAsync(string name, CancellationToken ct)
    {
        var store = Store();
        var remote = store.Load(name) ?? throw new UsageException($"Remote '{name}' not found in {store.FilePath}.");
        store.Save(await SignInAsync(remote, ct));
        Console.WriteLine($"Remote '{name}' signed in.");
        return ExitCodes.Ok;
    }

    private static async Task<int> ImportAsync(string? name, string? rclonePath, CancellationToken ct)
    {
        var path = rclonePath ?? RcloneImporter.DefaultPath;
        if (!File.Exists(path)) throw new UsageException($"rclone config not found: {path}");
        var store = Store();

        IReadOnlyList<Remote> candidates;
        try
        {
            candidates = RcloneImporter.ReadDriveRemotes(File.ReadAllText(path));
        }
        catch (RcloneConfigEncryptedException ex)
        {
            Console.WriteLine(ex.Message);
            Console.WriteLine("Create a gdup remote with a fresh sign-in instead.");
            await NewRemoteAsync(store, ct);
            return ExitCodes.Ok;
        }
        if (candidates.Count == 0) throw new UsageException($"No Google Drive (type = drive) remotes in {path}.");

        var source = name is null
            ? Prompt.Choose("rclone remote to import", candidates, r => r.Name)
            : candidates.FirstOrDefault(r => string.Equals(r.Name, name, StringComparison.OrdinalIgnoreCase))
              ?? throw new UsageException($"rclone remote '{name}' not found or not a Google Drive remote.");

        var target = Prompt.AskRequired("Name for the gdup remote", source.Name);
        if (store.Load(target) is not null && !Prompt.Confirm($"Remote '{target}' already exists. Overwrite?"))
            return ExitCodes.Ok;

        var remote = source with { Name = target };
        if (remote.ClientId.Length == 0)
        {
            Console.WriteLine("This rclone remote uses rclone's built-in OAuth client, which gdup cannot reuse.");
            Console.WriteLine(ClientHelp);
            remote = remote with
            {
                ClientId = Prompt.AskRequired("Client ID"),
                ClientSecret = Prompt.AskRequired("Client secret"),
                Token = null,
            };
        }
        if (remote.Token is null) remote = await SignInAsync(remote, ct);

        store.Save(remote);
        Console.WriteLine($"Imported rclone remote '{source.Name}' as '{remote.Name}' into {store.FilePath}");
        return ExitCodes.Ok;
    }

    private static async Task<Remote> SignInAsync(Remote remote, CancellationToken ct)
    {
        Console.WriteLine("Opening your browser to sign in to Google. If it does not open, visit:");
        using var http = HttpClientFactory.Create(null);
        var token = await OAuthLoopback.AuthorizeAsync(http, remote.ClientId, remote.ClientSecret, remote.Scope, url =>
        {
            Console.WriteLine(url);
            try
            {
                Process.Start(new ProcessStartInfo(url) { UseShellExecute = true });
            }
            catch (Win32Exception)
            {
                // No browser registered; the user can open the printed URL.
            }
        }, ct);
        Console.WriteLine("Signed in.");
        return remote with { Token = token };
    }
}
```

```csharp
using System.Net;
using Gdup.Auth;
using Gdup.Config;
using Gdup.Drive;
using Gdup.Net;
using Gdup.Output;

namespace Gdup.Cli;

/// <summary>Wires a remote, the chosen NIC, the HttpClient and tokens together for one upload run.</summary>
internal sealed class UploadSession : IDisposable
{
    private readonly HttpClient _http;
    private readonly TokenProvider _tokens;
    private readonly string _via;

    private UploadSession(Remote remote, HttpClient http, TokenProvider tokens, string via)
    {
        Remote = remote;
        _http = http;
        _tokens = tokens;
        _via = via;
        Drive = new DriveClient(http, tokens);
    }

    public Remote Remote { get; }
    public DriveClient Drive { get; }

    public static UploadSession Open(string remoteName, string? via)
    {
        var store = new ConfigStore(ConfigStore.DefaultPath);
        var remote = store.Load(remoteName)
            ?? throw new UsageException($"Remote '{remoteName}' not found in {store.FilePath}. Run: gdup config");
        if (remote.Token is null)
            throw new UsageException($"Remote '{remoteName}' is not signed in. Run: gdup config reconnect {remoteName}");

        IPAddress? bind = null;
        var viaText = "";
        if (via is not null)
        {
            var nics = NicSelector.ListUp();
            try
            {
                var (nic, address) = NicSelector.Select(via, nics);
                bind = address;
                viaText = $"{nic.Name} ({address})";
            }
            catch (NicNotFoundException ex)
            {
                throw new UsageException($"{ex.Message}{Environment.NewLine}Active interfaces:{Environment.NewLine}{NicsCommand.Render(nics)}");
            }
        }

        var http = HttpClientFactory.Create(bind);
        return new UploadSession(remote, http, new TokenProvider(remote, http, store.Save), viaText);
    }

    public async Task<int> RunAsync(UploadRequest request, CancellationToken ct)
    {
        var progress = new ProgressReporter(request.Name, _via, Console.Out, interactive: !Console.IsOutputRedirected);
        var uploader = new ResumableUploader(_http, _tokens, new SessionStore(SessionStore.DefaultDirectory), progress);
        var started = Stopwatch.StartNew();

        var result = await uploader.UploadAsync(request, ct);

        progress.Complete();
        Console.WriteLine($"Uploaded {result.Name} ({Format.Bytes(result.Size)}) in {Format.Duration(started.Elapsed)}, avg {Format.Rate(progress.AverageBytesPerSecond)}");
        Console.WriteLine($"Drive file id: {result.FileId}");
        switch (result.Md5Matches)
        {
            case true:
                Console.WriteLine($"MD5 verified: {result.LocalMd5}");
                return ExitCodes.Ok;
            case null:
                Console.WriteLine("Drive did not report an MD5; checksum not verified.");
                return ExitCodes.Ok;
            default:
                Console.Error.WriteLine(
                    $"MD5 MISMATCH: local {result.LocalMd5}, Drive {result.DriveMd5}. The Drive file ({result.FileId}) was kept; check it or upload again.");
                return ExitCodes.ChecksumMismatch;
        }
    }

    public void Dispose() => _http.Dispose();
}
```

```csharp
namespace Gdup.Cli;

internal static class ResumeCommand
{
    public static Command Create()
    {
        var file = new Argument<string?>("file") { Arity = ArgumentArity.ZeroOrOne, Description = "Local file of an interrupted upload (omit to list)" };
        var list = new Option<bool>("--list") { Description = "List interrupted uploads" };
        var via = new Option<string?>("--via") { Description = "Network interface name or local IP to upload through" };
        var stall = new Option<int>("--stall-timeout") { Description = "Seconds without progress before reconnecting (min 5)", DefaultValueFactory = _ => 60 };

        var cmd = new Command("resume", "List or continue interrupted uploads");
        cmd.Arguments.Add(file);
        cmd.Options.Add(list);
        cmd.Options.Add(via);
        cmd.Options.Add(stall);
        cmd.SetAction((ParseResult pr, CancellationToken ct) => CliRunner.RunAsync(async () =>
        {
            var sessions = new SessionStore(SessionStore.DefaultDirectory).List();
            var target = pr.GetValue(file);
            if (target is null || pr.GetValue(list))
            {
                if (sessions.Count == 0) Console.WriteLine("No interrupted uploads.");
                foreach (var (_, s) in sessions)
                {
                    Console.WriteLine(s.FilePath);
                    Console.WriteLine($"    -> {s.Remote}: {s.Name}  {Format.Bytes(s.Size)}  started {s.Created.ToLocalTime():yyyy-MM-dd HH:mm}");
                }
                return ExitCodes.Ok;
            }

            var fullPath = Path.GetFullPath(target);
            var state = sessions.Select(e => e.State)
                .LastOrDefault(s => string.Equals(s.FilePath, fullPath, StringComparison.OrdinalIgnoreCase))
                ?? throw new UsageException($"No interrupted upload found for {fullPath}. Run: gdup resume --list");
            if (!File.Exists(state.FilePath)) throw new UsageException($"File not found: {state.FilePath}");

            using var session = UploadSession.Open(state.Remote, pr.GetValue(via));
            var request = new UploadRequest(state.FilePath, state.Remote, state.FolderId, state.Name, state.ChunkSize,
                UploadCommand.StallTimeout(pr.GetValue(stall)));
            return await session.RunAsync(request, ct);
        }, ct));
        return cmd;
    }
```

````markdown
# gdup

Uploads one large file to Google Drive as fast as a single stream allows, using Drive's
resumable upload protocol. It can pin the upload to a specific network interface and
stores credentials rclone-style (DPAPI-encrypted) in `%APPDATA%\gdup\gdup.conf`.

## Setup

```
gdup config                      # create a remote (needs your own Desktop-app OAuth client)
gdup config import-rclone        # or copy a Drive remote from rclone.conf
gdup config show
```

## Upload

```
gdup nics                                        # list interfaces for --via
gdup upload D:\video\big.mkv gdrive:Backups/2026
gdup upload D:\video\big.mkv gdrive:Backups --via "Ethernet 2" --chunk-size 512M
```

If an upload is interrupted (Ctrl+C, crash, network loss), run the same command again or:

```
gdup resume --list
gdup resume D:\video\big.mkv
```

Exit codes: 0 ok, 1 usage/config error, 2 upload failed, 3 checksum mismatch.

Drive accepts only one ordered stream per file, so `--via` chooses the link; it does not
combine links.
````
